How a project runs

Four stages, each with a clear deliverable, so you always know what happens next.

1

2

3

Build

Questions you might have

How long does a website take?

It depends on the number of pages and how much animation you want. After our first call I send a clear estimate with fixed milestones.

How much does it cost?

I quote per project once I understand what you need, so you pay for the work and nothing extra.

Can you improve my existing website?

Yes. I can audit what you have, fix the biggest problems first and keep the parts that already work.

Will it work on phones?

Yes. Every page is built for phones first and tested on smaller screens before it goes live.

Services

Pick one service or combine them. Every project ends with code you own and documentation you can hand to another developer.

Front-end development

Responsive websites and web apps in HTML, CSS, JavaScript, TypeScript and React.

  • Component-based builds from your design or mine
  • Accessible markup and keyboard support
  • Handover with clear documentation

Motion and interaction

Scroll-driven storytelling with GSAP and Lenis that supports the message instead of distracting from it.

  • Page transitions, pinned sections and parallax
  • Reduced-motion fallbacks for every animation
  • Tested on real mid-range phones

Security-first builds

Protection built into the code, not added at the end.

  • Content Security Policy and security headers
  • Input validation, output escaping and safe forms
  • Dependency review and a written findings report

Audits and fixes

Already have a site? I review it and fix what matters most first.

  • Performance, accessibility and SEO checks
  • Front-end security review with prioritised fixes
  • Re-test after changes are made
